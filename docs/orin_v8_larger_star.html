Orin

Pilih bentuk dan warna Orin. Siluet lebih organik, bola benar-benar bulat, bintang dengan ujung dan lekukan yang lebih membulat serta ukuran body yang diperbesar agar seimbang dengan bentuk lain.

Rig (siap dipindah ke Rive)

Satu rig mata dipakai semua bentuk. Siluet tetap mewakili 15 bentuk yang sama, tetapi kontur dan shading dibuat lebih lembut. Di Rive, buat satu artboard per bentuk dengan hirarki identik, atau satu artboard dengan number input shape (0–14) yang menukar Body dan warna.

Bone / shapePivotDigerakkan oleh
Root › Body (bentuk + warna)tengahnapas halus, squash-stretch, bounce elastis, sway; bola memakai skala seragam agar tetap bulat
Body › Face (grup)tengahparallax tatapan yang dihaluskan, offset per bentuk
Face › EyeL, EyeR (kapsul gelap + highlight)tengah matatinggi, lebar, rotasi cermin, jarak, kedip, kilau mata
Eye › ArcShape (mata "^")tengah matacross-fade dengan kapsul saat senang
Root › FX (titik "...", "?", not ♪, "z")di atas / samping kepalafade dan melayang sesuai state atau aksi idle

Transisi memakai easing dan smoothing agar perpindahan pose tidak terasa patah. Gerakan napas dan sway dijaga kecil supaya Orin tetap tenang saat idle. State machine "Mascot": mood (0 idle, 1 listening, 2 thinking, 3 speaking, 4 happy, 5 confused), audioLevel 0–100, lookX/lookY −100..100, shape 0–14, trigger blink, nod, giggle, hum, look, tilt, yawn, hiccup, dan boolean sleep.

const { rive, RiveComponent } = useRive({ src: "/orin.riv", stateMachines: "Mascot", autoplay: true });
const mood  = useStateMachineInput(rive, "Mascot", "mood");
const shape = useStateMachineInput(rive, "Mascot", "shape");
mood.value = 2;   // agent berpikir
shape.value = 1;  // pilih bentuk awan
